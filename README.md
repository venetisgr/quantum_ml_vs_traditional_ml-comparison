# Classical vs Quantum vs Hybrid ML — thesis code

Reproducible code for a Master's thesis comparing classical, quantum, and hybrid
machine-learning models under matched conditions. The research questions,
datasets, model zoo, experiment suite (E0–E10), and fairness protocol are
defined in **[docs/groundwork.md](docs/groundwork.md)**; current progress lives
in **[STATUS.md](STATUS.md)**.

## Setup

```bash
conda env create -f environment.yml
conda activate qml-thesis
pip install -e .        # optional; a root conftest.py also wires up imports
```

## Usage

```bash
# Run an experiment (config-driven; one YAML per run family)
python experiments/run.py --config experiments/configs/e0_smoke.yaml

# Tests
pytest tests/
```

## The fairness protocol (short version — full version in groundwork §8)

- **One set of splits, forever.** 5-fold stratified CV × 5 seeds per dataset,
  generated once by `data/make_splits.py`, committed under `data/splits/`, and
  read by every model. The runner refuses to run without a stored splits file
  and `make_splits.py` refuses to overwrite one.
- **Matched tuning budget** for classical and quantum models (same Optuna
  trial count; see §8 for the exact procedure).
- **Shared preprocessing:** every model consumes the same per-feature
  min–max scaling to [0, π] (angle-encoding range), fit on the training fold
  only.
- **Append-only results:** every run appends rows to `results/<experiment>.csv`
  with dataset, model, config hash, seed, split id, regime, parameter count,
  and metrics. Simulation regimes are never mixed in one table.
- **No hand-typed numbers:** every thesis figure/table is regenerated by a
  script in `analysis/`.

## Layout

| Path | Contents |
|---|---|
| `data/` | dataset loaders (`synthetic.py`, `tabular.py`, `images.py`), `preprocessing.py`, `make_splits.py`, stored splits in `splits/` |
| `models/` | `classical.py` (E0/E1), `qkernels.py` (E2), `vqc.py` (E3), `qcnn.py`, `hybrid.py` (E5) |
| `experiments/` | `run.py` + one YAML per run family in `configs/` |
| `analysis/` | statistics + plotting scripts; source of every thesis figure |
| `results/` | append-only CSV logs (git-tracked; schema in `results/README.md`) |
| `notebooks/` | exploration only, never source of truth |
| `docs/` | `groundwork.md` — the master plan |
