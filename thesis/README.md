literature backbone are defined in `docs/groundwork.md` (§2, §4).

## Build

```bash
cd thesis
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Conventions

- **No hand-typed numbers.** Every empirical figure/table is generated by a
  script in `analysis/` and included from `analysis/output/`; numeric claims in
  prose are marked with `\resultref{...}` until wired to a generated artifact.
- All notation lives in `macros.tex`; do not define symbols inside chapters.
- `\todonote{...}` marks every unresolved decision; grep for it before any
  submission milestone.
- The preamble is template-agnostic on purpose — swap in the university class
  when it is known (groundwork §12, open question 1) without touching chapters.
